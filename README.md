# AI Literacy Scorecard — bản sơ cấp

## Chạy thử
1. Cài Python.
2. Trong thư mục này, chạy `pip install -r requirements.txt`.
3. Chạy `streamlit run app.py`.

## Xuất bản thành link
1. Tạo repository trên GitHub.
2. Tải `app.py` và `requirements.txt` lên repository.
3. Vào https://share.streamlit.io/ và đăng nhập bằng GitHub.
4. Chọn Create app, chọn repository, nhánh `main`, file `app.py`, rồi Deploy.
5. Khi chạy thành công, sao chép link `*.streamlit.app` được cấp.

## Lưu ý
Đây là nguyên mẫu sơ cấp, chưa phải thang đo đã được kiểm định. Cần nhờ giáo viên duyệt các câu hỏi/ngưỡng diễn giải. Không khẳng định Cronbach's alpha đạt yêu cầu khi chưa phân tích dữ liệu thật.
